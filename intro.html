O que é este levantamento?

A Equação de Drake

Em 1961, Frank Drake propôs uma equação para estimar o número de civilizações tecnológicas detectáveis na Via Láctea.

N = R* · fp · ne · fl · fi · fc · L

N = número de civilizações detectáveis hoje na Via Láctea

Por que um levantamento?

Os valores dos parâmetros são profundamente incertos e dependem de áreas do conhecimento muito distintas.

Como funciona

  1. Para cada parâmetro você moverá um controle deslizante que define uma distribuição de probabilidade.
  2. Ao final, sua distribuição pessoal de N será calculada.
  3. Você poderá retornar mais tarde para consultar os resultados agregados.
